Windows kurulum paketi Sürümler
Otomatik jeton toplama TikTok tarafından sunulmaz. Uygulama sandığı süresi dolmadan gösterir ve canlıya tek tıkla götürür.

Sürekli tarama nasıl çalışır?

Tarama GitHub sunucularında döner; bilgisayarın kapalı olsa bile yeni yayıncılar ve sandıklar bulunur.

GitHub Actions · cron */5
  → aday yayıncılar (Tik.Tools, TikWM, dizin)
  → user/room + check_alive doğrulama
  → room/info → sandık zarfı
  → web/data/arena-live.json
  → GitHub Pages + Windows Radar

Veri akışı: web/data/arena-live.json. Windows uygulaması ham GitHub adresini 5 saniyede bir sorgular, değişiklik yoksa bant genişliği harcamaz.
